UniBridge Documentation

What UniBridge Does

UniBridge is a coordination layer for cross-border payouts.

It allows applications and wallets to determine how a payout will be executed across multiple regulated partners — before any funds move.

UniBridge does not custody funds. It resolves execution first, then enforces it.

Architecture

UniBridge separates payout coordination into layers:

Client Application → Session → Routing → Settlement → Execution

UniBridge does not hold funds or execute payouts directly. It coordinates execution across partners.

Execution Lifecycle

The payout flow follows a deterministic sequence:

Session → Route Resolution → Settlement → Route Lock → Funding → Execution

Execution is committed before funds move.

Use Case

A remittance app initiates a payout:

  • Create session
  • Resolve execution route
  • Lock route
  • Fund transaction
  • Execute payout

Funds are delivered through local rails like bank transfer or PIX.

Execution Model

UniBridge ensures that execution is defined before funding.

This eliminates uncertainty between settlement and payout.

Deterministic execution is the core principle.
