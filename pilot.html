UniBridge Pilot

Controlled Route Pilot Pack

A public overview of how UniBridge runs controlled payout route review: route creation, lifecycle visibility, access boundaries, credential handling, and production approval boundaries.

What This Pilot Covers

Create a controlled UniBridge-managed payout route.
Receive a route identifier for operational review.
Review simplified partner-facing route status.
Validate the flow before any production activation.

What This Pilot Does Not Cover

  • Production payout volume
  • Direct provider access
  • Provider credentials
  • Bulk payout creation
  • Partner-controlled automated retries
  • Unrestricted production API access

Route Lifecycle

Each route moves through a controlled UniBridge-managed lifecycle. Partner-facing statuses are simplified for pilot review and do not expose internal provider logic or execution secrets.

route locked → funding pending → funding detected → execution submitted → payout pending → payout completed

Security & Credential Handling

  • No credentials are included in public documents.
  • Pilot credentials are shared separately through private channels.
  • Access is limited to the approved partner scope.
  • Internal execution secrets are not exposed.
  • Status access is limited to partner-owned routes.

Production Boundary

The pilot is intended for controlled route validation only. Production rollout, production volume, webhook access, or broader API access require separate approval and review.

UniBridge coordinates non-custodial payout routes for stablecoin-settled payout corridors.
