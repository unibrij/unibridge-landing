Explore bank connectivity, payment initiation, and collection models available through UniBridge and its infrastructure partners.

Public integration overview

Integration overview

UniBridge connects bank payment initiation with fiat collection and settlement infrastructure, enabling partners to build collection flows around their operational requirements.

Partners can explore bank connectivity through the public Bank Discovery API and evaluate the collection and settlement models described below.

API availability: Bank Discovery is publicly accessible without authentication. Payment initiation and settlement integrations require partner-specific configuration and authorization.

1. Public Bank Discovery API

Retrieve available institutions for a country using its two-letter ISO country code.

Base URL

https://unibridge-v2-1066944028362.us-central1.run.app

Endpoint

GET /v2/fiat/connected-bank/exthand/public-banks?countryCode=GB

Country parameter

Use the countryCode parameter to explore different countries. Examples include GB (United Kingdom), DE (Germany), FR (France), and NL (Netherlands).

Country codes are query examples. Actual bank coverage depends on the connectivity provider.

Request example

curl 'https://unibridge-v2-1066944028362.us-central1.run.app/v2/fiat/connected-bank/exthand/public-banks?countryCode=GB'

Example response

{
  "ok": true,
  "countryCode": "GB",
  "banks": [
    {
      "connectorId": 9,
      "name": "Revolut"
    },
    {
      "connectorId": 2265,
      "name": "Wise"
    }
  ]
}

Abridged example from a successful UK query. The live response may include additional institutions.

Response fields

ok — Indicates request success.

countryCode — Requested country.

banks — Array of institutions containing connectorId and name.

Invalid country codes return an error response. Temporary provider failures may also result in an error. Bank discovery does not initiate a payment.

2. Payment Initiation (PIS)

UniBridge integrates with bank connectivity infrastructure to support payment initiation from eligible customer bank accounts.

Integration flow

1. Bank selection: The customer selects an available financial institution.

2. Payment initiation: A payment request is prepared for the selected institution and collection destination.

3. Bank authorization: The customer completes the required authorization through the supported bank flow.

4. Payment status: The integration tracks the payment initiation outcome and the available downstream status.

Partner integration

Partner API specifications, authentication requirements, and payment status handling are shared as part of the integration process.

Bank authorization does not by itself guarantee successful settlement or receipt of funds.

3. Collection and settlement models

UniBridge supports different integration approaches depending on the partner's collection and settlement needs.

Standalone PIS

Integration option

Bank payment initiation using an agreed collection destination and payment flow.

PIS + Virtual Accounts

Partner configuration

Fiat collection into virtual accounts provisioned through UniBridge's infrastructure partners.

PIS + Stablecoin Settlement

Partner configuration

Fiat collection and conversion into stablecoins, with settlement to a wallet designated by the partner.

Availability depends on supported jurisdictions, infrastructure capabilities, compliance requirements, and commercial arrangements.

4. Integration next steps

Partners can begin by exploring the public Bank Discovery API to review available institutions.

Once the preferred collection model is identified, UniBridge can provide the relevant integration specifications and coordinate the technical and operational requirements.

The integration can be structured around standalone payment initiation, virtual account collection, or stablecoin settlement.
