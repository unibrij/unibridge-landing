Fiat Collection & Payment Initiation

Explore bank connectivity and PIS-powered fiat collection into partner-designated accounts or virtual accounts provisioned through UniBridge's infrastructure partners, with optional settlement capabilities.

Public integration overview

Integration overview

UniBridge connects bank payment initiation with fiat collection infrastructure, enabling partners to collect funds into agreed destination accounts without requiring a single account-provisioning model.

Collection accounts may be provided by the partner or provisioned through UniBridge's infrastructure partners, depending on the integration requirements.

Partners can explore bank connectivity through the public Bank Discovery API and evaluate the collection models described below.

API availability: Bank Discovery is publicly accessible without authentication. Payment initiation, account configuration, and settlement integrations require partner-specific authorization and configuration.

1. Public Bank Discovery API

Retrieve available institutions for a country using its two-letter ISO country code.

Base URL

https://unibridge-v2-1066944028362.us-central1.run.app

Endpoint

GET /v2/fiat/banks?countryCode=GB

Country parameter

Use the countryCode parameter to explore different countries. Examples include GB (United Kingdom), DE (Germany), FR (France), and NL (Netherlands).

Country codes are query examples. Actual bank coverage depends on the connectivity provider.

Request example

curl 'https://unibridge-v2-1066944028362.us-central1.run.app/v2/fiat/banks?countryCode=GB'

Example response

{
  "ok": true,
  "countryCode": "GB",
  "banks": [
    {
      "connectorId": 9,
      "name": "Revolut"
    },
    {
      "connectorId": 2265,
      "name": "Wise"
    }
  ]
}

Abridged example from a successful UK query. The live response may include additional institutions.

Response fields

ok — Indicates request success.

countryCode — Requested country.

banks — Array of institutions containing connectorId and name.

Invalid country codes return an error response. Temporary provider failures may also result in an error. Bank discovery does not initiate a payment.

2. Payment Initiation (PIS)

Payment initiation is a component of the UniBridge fiat collection flow. It enables eligible customers to authorize bank payments toward an agreed collection destination.

Integration flow

1. Bank selection: The customer selects an available financial institution.

2. Payment initiation: A payment request is prepared for the selected institution and configured collection destination.

3. Bank authorization: The customer completes the required authorization through the supported bank flow.

4. Payment status: The integration tracks the payment initiation outcome and the available downstream status.

Partner integration

Partner API specifications, authentication requirements, destination account configuration, and payment status handling are shared as part of the integration process.

Bank authorization does not by itself guarantee successful settlement or receipt of funds.

3. Fiat collection models

UniBridge supports two collection approaches, depending on who provides the destination account. Both use payment initiation as part of the collection flow.

Partner-Provided Accounts

Collection model

Fiat collection into an agreed account designated by the partner, including eligible existing virtual accounts, subject to destination account support and integration requirements.

UniBridge-Provided Virtual Accounts

Partner configuration

Fiat collection into virtual accounts provisioned through UniBridge's infrastructure partners, subject to account availability, onboarding, and compliance requirements.

Optional stablecoin settlement

Depending on the selected collection model and supported infrastructure, collected fiat may be converted into stablecoins and settled to a wallet designated by the partner.

Collection and settlement availability depends on supported jurisdictions, banking connectivity, infrastructure capabilities, compliance requirements, and commercial arrangements. Stablecoin settlement is not implied by bank payment authorization alone.

4. Integration next steps

Partners can begin by exploring the public Bank Discovery API to review available institutions.

The next step is to identify the preferred collection destination: an eligible account provided by the partner or a virtual account provisioned through UniBridge's infrastructure.

UniBridge can then coordinate the relevant integration specifications, payment initiation requirements, account configuration, and optional settlement arrangements.
