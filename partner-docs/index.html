Current status: UniBridge is available only for controlled testing, partner evaluation, and private integration review. It is not a public remittance service and should not be treated as production infrastructure unless separately approved in writing.

Core controlled execution path

/v2/session/register
→ /v2/session/resolve
→ /v2/session/quote
→ /v2/settlement/create
→ /v2/funding/session
→ provider-handled funding
→ funding observed / confirmed
→ /v2/settlement/confirm
→ execution readiness check
→ execution submission
→ execution provider reference recorded
→ provider status reconciliation
→ /v2/settlement/status
Funding confirmation alone does not represent final execution completion. Settlement confirmation dispatch alone does not represent final execution completion.
