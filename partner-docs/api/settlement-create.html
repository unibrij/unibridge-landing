API Reference

Create Settlement

POST /v2/settlement/create

Creates a settlement from a quoted route, destination payout details, and optional redirect URL.

Settlement creation also creates the corresponding funding session and stores the execution route context used after funding confirmation and settlement confirmation dispatch.

Request body

FieldTypeRequiredDescription
session_idstringYesQuoted session ID.
route_idstringYesSelected route returned by quote.
destinationobjectYesCorridor-specific payout destination details.
redirect_urlstringConditionalRequired for widget-capable sender flows.

Example request

{
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000",
  "route_id": "route_123",
  "redirect_url": "https://www.unibrij.io/surface",
  "destination": {
    "type": "pix",
    "pix_key": "recipient@example.com"
  }
}

Example response

{
  "settlement_id": "sett_123e4567-e89b-12d3-a456-426614174000",
  "funding_session_id": "sett_123e4567-e89b-12d3-a456-426614174000",
  "status": "waiting_ramp_payment",
  "funding_method": "sender",
  "sender_id": "onramp"
}

Destination details

Destination details are corridor-specific. For Brazil PIX testing, the destination payload may include: 

{
  "type": "pix",
  "pix_key": "recipient@example.com"
}

Possible errors

ErrorMeaning
missing_session_idsession_id was not provided.
session_not_foundSession does not exist.
quote_not_completedSession must be quoted before settlement creation.
invalid_route_selectionSelected route_id is invalid or unavailable.
invalid_destinationDestination payout details are missing or invalid.
redirect_url_requiredA redirect URL is required for the selected sender flow.
