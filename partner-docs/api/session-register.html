API Reference

Register Session

POST /v2/session/register

Creates a controlled integration session for a source country and destination country.

Authentication

This endpoint is a partner POST request and requires HMAC authentication unless otherwise agreed. 

Content-Type: application/json
x-ub-partner-id: <partner_id>
x-ub-signature: <hex_hmac_signature>

Request body

FieldTypeRequiredDescription
source_countrystringYesSource country code or supported source region.
receiver_countrystringYesDestination country code.

Example request

{
  "source_country": "DE",
  "receiver_country": "BR"
}

Example response

{
  "ok": true,
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000"
}

Possible errors

ErrorMeaning
invalid_source_countrySource country is missing or unsupported.
invalid_receiver_countryReceiver country is missing or unsupported.
corridor_not_supportedThe requested corridor is not available.
partner_not_authorizedPartner is not authorized for this corridor or action.
