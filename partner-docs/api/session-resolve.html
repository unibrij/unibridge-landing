API Reference

Resolve Session

POST /v2/session/resolve

Resolves funding sender options and execution options for the registered session.

This step prepares the controlled execution path before payment or funding begins.

Request body

FieldTypeRequiredDescription
session_idstringYesSession returned by /v2/session/register.

Example request

{
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000"
}

Example response

{
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000",
  "status": "resolved",
  "source_country": "DE",
  "receiver_country": "BR",
  "sender_id": "onramp",
  "delivery_options": {
    "sender": {
      "id": "onramp",
      "funding_mode": "ramp"
    },
    "execution": {
      "pix": [
        {
          "executor": "smartpay",
          "instruction_schema": {
            "type": "object",
            "required": ["pix_key"]
          }
        }
      ]
    }
  }
}

Resolved context

  • Funding sender or checkout path
  • Execution provider options
  • Destination payout rail requirements
  • Corridor-specific constraints

Possible errors

ErrorMeaning
missing_session_idsession_id was not provided.
session_not_foundSession does not exist.
corridor_not_supportedNo supported route exists for the session corridor.
resolve_failedUniBridge could not resolve sender or execution options.
