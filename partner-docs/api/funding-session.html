API Reference

Funding Session

POST /v2/funding/session

Returns the funding session created for a settlement.

Depending on the selected sender, this may return a provider checkout URL or direct funding instructions.

Request body

FieldTypeRequiredDescription
settlement_idstringYesSettlement created through /v2/settlement/create.

Example request

{
  "settlement_id": "sett_123e4567-e89b-12d3-a456-426614174000"
}

Important behavior

A funding session provides funding or checkout instructions. It does not represent final payout completion. Final completion depends on funding observation, settlement confirmation dispatch, execution submission, and provider status reconciliation.

Possible errors

ErrorMeaning
missing_settlement_idsettlement_id was not provided.
settlement_not_foundSettlement does not exist.
funding_session_not_foundFunding session does not exist.
funding_session_expiredFunding session has expired.
