API Reference

Quote Session

POST /v2/session/quote

Generates route and pricing information for a resolved session.

A quote prepares the route for settlement creation and post-funding execution planning.

Request body

FieldTypeRequiredDescription
session_idstringYesResolved session ID.
amountnumberYesTest amount requested for the controlled payout.

Example request

{
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000",
  "amount": 10
}

Example response

{
  "status": "quoted",
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000",
  "requested_amount": 10,
  "payout_amount": 10,
  "amount": 10,
  "routes": [
    {
      "route_id": "route_123",
      "route_type": "executor",
      "executor": "smartpay",
      "execution_provider": "smartpay",
      "payout_rail": "pix",
      "network": "polygon",
      "asset": "USDT",
      "fx_rate": null,
      "executor_fee": 0,
      "unibridge_fee": 0,
      "funding_amount": 10,
      "funding_asset": "USDT",
      "funding_network": "polygon",
      "est_time": "Instant"
    }
  ]
}

Route fields

FieldMeaning
route_idRoute identifier used during settlement creation.
executor / execution_providerConfigured provider expected to execute the payout after funding confirmation.
payout_railDestination payout rail, such as PIX.
funding_assetAsset expected in the funding leg.
funding_networkNetwork expected in the funding leg.
funding_amountAmount expected for the selected funding or sender route.

Important behavior

A quote does not move funds. A quote does not guarantee final execution. A quote prepares available routes for review before settlement creation.

Possible errors

ErrorMeaning
missing_session_idsession_id was not provided.
session_not_foundSession does not exist.
resolve_not_completedSession must be resolved before quoting.
invalid_amountAmount is missing, invalid, or outside allowed limits.
route_not_availableNo executable route is available.
