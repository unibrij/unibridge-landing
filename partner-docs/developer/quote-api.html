Developer Integration

Quote API

The quote flow prepares the payout route before payment or funding begins.

Current quote flow

POST /v2/session/register
POST /v2/session/resolve
POST /v2/session/quote

1. Register session

POST /v2/session/register

Creates a controlled test session for a source country and destination country.

{
  "source_country": "DE",
  "receiver_country": "BR"
}
{
  "ok": true,
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000"
}

2. Resolve session

POST /v2/session/resolve

Resolves the funding sender and available execution options for the selected corridor. This step prepares both sides of the controlled flow before funds move.

  • Funding sender or checkout path
  • Execution provider options
  • Destination payout rail requirements
{
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000"
}
{
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000",
  "status": "resolved",
  "source_country": "DE",
  "receiver_country": "BR",
  "sender_id": "onramp",
  "delivery_options": {
    "sender": {
      "id": "onramp",
      "funding_mode": "ramp"
    },
    "execution": {
      "pix": [
        {
          "executor": "smartpay",
          "instruction_schema": {
            "type": "object",
            "required": ["pix_key"]
          }
        }
      ]
    }
  }
}

3. Request quote

POST /v2/session/quote

Generates executable route options and pricing fields for the resolved session. A quoted route should contain the information needed to create a settlement and support post-funding execution. 

{
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000",
  "amount": 10
}
{
  "status": "quoted",
  "session_id": "sess_123e4567-e89b-12d3-a456-426614174000",
  "requested_amount": 10,
  "payout_amount": 10,
  "amount": 10,
  "routes": [
    {
      "route_id": "route_123",
      "route_type": "executor",
      "executor": "smartpay",
      "execution_provider": "smartpay",
      "payout_rail": "pix",
      "network": "polygon",
      "asset": "USDT",
      "fx_rate": null,
      "executor_fee": 0,
      "unibridge_fee": 0,
      "funding_amount": 10,
      "funding_asset": "USDT",
      "funding_network": "polygon",
      "est_time": "Instant"
    }
  ]
}

Important behavior

A quote does not move funds. A quote does not guarantee final execution. A quote prepares available routes for review before settlement creation and before any post-funding execution can occur.
