Environments

Environment access is issued privately for approved partner integration review.

/v2

Environment access

Actual API URLs, credentials, corridor access, and test limits are issued privately to approved partners.

EnvironmentPurpose
localInternal UniBridge development and testing.
controlled testControlled partner evaluation and small-value integration testing.
productionProduction use only after separate written approval.

Credential separation

  • Use only the credentials issued for the approved environment.
  • Do not share credentials outside the approved integration team.
  • Do not expose credentials in frontend code.
  • Do not commit credentials to source control.
  • Do not assume test access creates production access.

Corridor availability

Corridor availability may differ by environment and partner scope.

  • Unavailable
  • Available for internal testing
  • Available for controlled partner testing
  • Approved for production use

Test limits

Controlled testing may include:

  • Small-value transactions only
  • Selected destination corridors only
  • Selected funding senders only
  • Manual review where required
  • No public remittance availability
Successful controlled testing does not automatically create production approval. Production use requires separate written approval from UniBridge.
