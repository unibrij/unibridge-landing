Error Handling

Common error categories and recommended partner handling during controlled integration review.

Error response format

Responses may use an error shape similar to:

{
  "ok": false,
  "error": "missing_session_id",
  "message": "session_id is required"
}

Authentication errors

ErrorMeaningSuggested action
missing_partner_idPartner ID header is missing.Send x-ub-partner-id.
missing_signatureSignature header is missing.Send x-ub-signature.
invalid_signatureHMAC signature does not match the raw request body.Recompute the signature using the exact raw JSON body.
partner_not_authorizedPartner is not authorized for this action or corridor.Confirm partner scope with UniBridge.

Session errors

ErrorMeaningSuggested action
missing_session_idsession_id was not provided.Include session_id.
session_not_foundSession does not exist.Confirm the session ID.
resolve_not_completedSession was not resolved before quote or settlement.Call /v2/session/resolve.
quote_not_completedQuote is required before settlement creation.Call /v2/session/quote.

Corridor and route errors

ErrorMeaningSuggested action
corridor_not_supportedSelected corridor is not available.Use an approved corridor.
route_not_availableNo executable route is available.Confirm sender and executor availability.
invalid_route_selectionSelected route does not match the session or corridor.Use a route returned by quote.
invalid_amountAmount is missing, invalid, or outside limits.Use an approved small-value test amount.

Funding errors

ErrorMeaningSuggested action
missing_settlement_idsettlement_id was not provided.Include settlement_id.
settlement_not_foundSettlement does not exist.Confirm the settlement ID.
funding_session_not_foundFunding session does not exist.Confirm settlement creation completed.
funding_session_expiredFunding session expired.Create a new settlement if required.
funding_not_confirmedFunding has not been observed or confirmed.Wait for confirmation before settlement confirmation dispatch.

Execution and reconciliation errors

ErrorMeaningSuggested action
invalid_settlement_stateThe settlement is not in a state that can continue.Check settlement status and avoid blind retries.
execution_not_readyFunding confirmed but execution readiness checks failed.Review settlement evidence or request manual review.
execution_already_submittedExecution was already submitted.Do not retry without review.
provider_ref_missingExecution provider reference was not recorded where expected.Request reconciliation.
manual_resume_requiredOperator review is required before continuing.Contact UniBridge with the settlement ID.
execution_retryableExecution may be retried safely under approved conditions.Follow UniBridge instructions.
Partners should not retry settlement confirmation or execution-related actions blindly. If the resulting state is unclear, rely on status retrieval and manual review.
