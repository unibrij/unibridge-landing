Execution Flow

A controlled UniBridge test follows a staged execution flow.

Flow

  1. Source country, destination country, and amount are selected.
  2. UniBridge prepares the execution path before payment begins.
  3. A quote is generated for review.
  4. Required destination payout details are provided.
  5. Payment is handled by the provider shown during checkout.
  6. Provider-handled funding is observed and confirmed.
  7. The funded settlement is dispatched into the next operational step.
  8. Execution readiness is checked.
  9. Execution is submitted to the configured execution provider.
  10. A provider reference is recorded when execution is accepted.
  11. Provider status is reconciled.
  12. Final status is updated based on the execution outcome.

Key principle

The execution path is prepared before funds move. UniBridge coordinates and tracks the execution process without taking custody of funds.

Funding confirmation alone does not represent final execution completion. Final completion requires execution submission, provider reference recording where applicable, and provider status reconciliation.
