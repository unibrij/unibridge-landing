Partner Evaluation

Execution Evidence

UniBridge records evidence during controlled test execution to support partner review and operational validation.

Evidence may include

  • Settlement identifier
  • Funding session status
  • Observed funding transaction
  • Observed asset and amount
  • Funding confirmation source
  • Execution provider
  • Provider reference
  • Provider status
  • Normalized execution status
  • Final settlement status
  • Relevant timestamps

Completion signal

A test is considered completed only when execution has been submitted, a provider reference has been recorded, and provider status reconciliation confirms a successful execution outcome.

Funding confirmation alone does not represent final execution completion.
