Security Review

Security Review

UniBridge completed an external security assessment as part of its controlled pilot readiness process.

Reviewed scope

The assessment was performed by YBUGS and covered the UniBridge Protocol · Bridge API during November 2025.

The assessment focused on the Bridge API scope available at the time of review, including API endpoints under /api/bridge/*.

  • Route quote generation
  • Settlement creation
  • Settlement confirmation
  • Settlement status lookup
  • Webhook callback processing
  • HMAC signature logic

Summary outcome

The external assessment reported no exploitable vulnerabilities identified in the reviewed scope.

The report also recorded zero Critical, High, Medium, or Low alerts across the assessed API security categories, with the overall security posture within the reviewed scope marked as GOOD.

Tested areas

The assessment included checks covering OWASP API Top 10 and CWE/SANS Top 25 categories, including authentication, authorization, IDOR, SQL injection, XSS, CSRF, SSRF, CORS, rate limiting, and exposed debug information.

Current integration surface

UniBridge’s current controlled partner integration documentation references the /v2 API surface. The prior YBUGS assessment should be understood as evidence of external security review for the earlier Bridge API scope, not as a blanket security certification for every current or future endpoint.

Current /v2 access remains private, controlled, credentialed, and subject to partner scope, operational readiness, and additional review where appropriate.

Report access

The full report is confidential and distribution-limited. It may be shared with qualified partners during diligence where appropriate.
